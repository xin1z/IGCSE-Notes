### Some definitions

__Element:__ substance containing only one type of atom.

__Atom:__ cannot be broken into anything simpler by chemical means.

__Compound:__ two or more atoms chemically bonded together.

__Mixture:__ two or more substances that are not chemically bonded.

__Proton number / Atomic number:__ the number of proton(s) in the nucleus of an atom.

__Mass number / Nucleon number:__ the total number of protons and neutrons in the nucleus of an atom.

| Name     | Relative charge | Relative mass |
| -------- | --------------- | ------------- |
| Proton   | +1              | 1             |
| Neutron  | 0               | 1             |
| Electron | -1              | 0             |

__Relative atomic mass / A<sub>r</sub>:__ the average mass of the isotopes of an element compared to 1/12 of the mass of a <sup>12</sup>C atom.

__Isotopes:__ different atoms of the same element that have the same number of protons but different number of neutrons.

|                    | Mass number                                                         | Relative atomic mass                                                                                  |
| ------------------ | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Definition         | the total number of protons and neutrons in the nucleus of an atom. | the average mass of the isotopes of an element compared to 1/12 of the mass of a <sup>12</sup>C atom. |
| Is a whole number? | Yes                                                                 | Usually no                                                                                            |
| Descriptive scope  | Describe atoms                                                      | Describe elements                                                                                     |

Isotopes have the same _chemical properties,_ because:

- They have the same number of electrons
- Therefore same electronic configuration
